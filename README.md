# ChatGPT Mini

Aplicación web Full Stack desarrollada con React, Node.js y Tailwind CSS v4.

## Características

* Respuestas dinámicas automáticas basadas en reglas
* Interfaz responsiva inspirada en ChatGPT con modo oscuro
* Scroll automático al recibir nuevos mensajes
* Indicador visual de escritura ("Escribiendo...")
* Arquitectura desacoplada mediante un Monorepo

## Tecnologías

* React (Vite)
* Node.js (Express)
* Tailwind CSS v4
* Axios
* CORS

## Instalación

1. Clonar el repositorio
2. Configurar el Backend:
   ```bash
   cd backend
   npm install
   npm run dev
